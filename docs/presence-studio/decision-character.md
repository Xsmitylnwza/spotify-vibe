## Question

ใช้ตัวละครเดียวหลายสภาพ หรือหลายตัวตามกิจกรรม? แนะนำตัวเดียวเพื่อให้คนพบซ้ำแล้วจำได้ ผู้ใช้ตอบว่า “ยังไม่เลือก ขอเห็นแนวทางก่อน” จึงยังเปิดการตัดสินใจนี้ และนำเสนอตัวอย่างโดยไม่ล็อกตัวละคร

## แนวทางเพื่อเปรียบเทียบ

คำชี้นำล่าสุดแทนทางเลือกมาสคอตด้านล่าง: ผู้ใช้เลือกคนชิบิน่ารักแนว 8-bit เป็นตัวแทนเจ้าของ เปลี่ยนสีหน้าและชุดตามอารมณ์ ดู [ทิศทางคนชิบิ](human-chibi-direction.md) ยังไม่กำหนดรูปลักษณ์จริงและชุดอารมณ์สุดท้าย

อัปเดตจากผู้ใช้: อยากได้ใบหน้าแนว 8-bit น่ารัก สีสด ทำ original artwork เองด้วย SVG หรือวิธีที่แก้ไขได้แล้ว export GIF และมีลิงก์เปิดเว็บไปดูตัวตน/ของที่ทำ ล็อกทิศทางภาพนี้ได้ แต่ยังไม่ถือว่าเลือกชนิดตัวละครหรือ palette สุดท้าย มี [ผลวิจัยและตัวอย่าง GIF](discord-surface-research.md) ไว้ให้ตอบสนองต่อร่าง

- หุ่นนอกเวลา: หุ่นตัวเดิม ซ่อมวงจรตอน Coding ถือประแจเข้าเกม แบตและชุดเปลี่ยนตามระยะเวลา เหมาะกับกี๊กกวน ๆ
- สัตว์ประหลาดประจำเครื่อง: ก้อนมีชีวิตตัวเดิม กินหน้าต่าง/คาบเมาส์/นอนทับคีย์บอร์ด เหมาะกับความปั่นและรูปทรงจำง่าย
- นักเดินทางหลายร่าง: นักเวทตอน Coding นักรบตอน Gaming วิญญาณตอน Away แต่ใช้หน้า/ตรา/สีร่วมกัน เหมาะกับการเปลี่ยนภาพจัดเต็ม แลกกับความยากในการคุมให้จำว่าเป็นคนเดียว
