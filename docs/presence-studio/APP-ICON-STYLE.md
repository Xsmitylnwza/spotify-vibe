# Application icon style

2026-09-06: app icons use a white 128px tile with a 96px logo centered inside. New locally extracted icons also receive this normalization. Codex uses the blue/purple terminal mark from https://raw.githubusercontent.com/lobehub/lobe-icons/master/packages/static-svg/icons/codex-color.svg instead of the current black ChatGPT mark. Source project: https://github.com/lobehub/lobe-icons (MIT).

Nine current app badges are hosted at presence-assets revision f1e2f793d9c30b6a9f42007631fb69087fa4cc99. Unknown future apps still need public badge assets for Discord; their local Studio icons are normalized automatically. The active application's display name replaces the preset activityName at delivery time; activity type, character and detail text remain owned by the preset. Shared presets are not mutated.
