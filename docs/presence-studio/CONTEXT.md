# Automatic Character Presence

คำศัพท์สำหรับทิศทางการออกแบบใหม่นี้ แยกจาก glossary ของแอป scheduled Presence ที่ยังใช้งานอยู่

## Language

**Character**:
ตัวตนภาพที่เป็นตัวแทนเจ้าของ มีใบหน้าหรือเอกลักษณ์ร่วมกันในสภาพต่าง ๆ
_Avoid_: Discord avatar

**Character Form**:
สภาพภาพและบุคลิกของ Character ในกิจกรรมหรือเหตุการณ์หนึ่ง
_Avoid_: รูปสุ่ม

**Personal Space**:
หน้าเว็บสาธารณะที่ผู้ชมเปิดจาก Rich Presence เพื่อสำรวจตัวตน รสนิยม และสิ่งที่เจ้าของเลือกโชว์
_Avoid_: Public Room, เรื่องราวมาสคอต, Presence Studio, หน้าตั้งค่า

**App Mapping**:
คู่ระหว่างแอปที่เจ้าของเลือกกับการ์ด Presence ที่เจ้าของกำหนดให้แสดงขณะใช้งานแอปนั้น
_Avoid_: สถานะที่ AI เดาให้

**Presence Studio**:
พื้นที่ส่วนตัวของเจ้าของสำหรับแต่งและควบคุมการนำเสนอ Character และ Presence
_Avoid_: Personal Space
