# ทิศทางคาแรคเตอร์: คนชิบิ Pixel Art

อัปเดตจากผู้ใช้ 2026-09-05 ใช้แทนภาพมาสคอตสีเขียว/หุ่น/สัตว์ประหลาดที่เคยเสนอ ตัวอย่าง GIF ใน character-study เป็นการทดลอง pipeline เดิม ไม่ใช่แบบอ้างอิงของตัวละครที่จะทำต่อ

## สิ่งที่ผู้ใช้กำหนด

- เป็นคนชิบิหน้าตาน่ารักที่เป็นตัวแทนเจ้าของ
- ภาษาภาพแนว 8-bit pixel art สีสด
- เปลี่ยนสีหน้า คาแรคเตอร์การแสดงออก และชุดตามอารมณ์
- งานภาพสร้างเองจากต้นฉบับที่แก้ไขได้ เช่น SVG แล้ว export เป็น GIF

## แนวทางเสนอเพื่อทำต่อ

คงเอกลักษณ์ใบหน้า ทรงผม และลักษณะจำของคนเดิม แล้วแยก 3 ส่วน: ตัวตนพื้นฐาน, อารมณ์, และชุด/เครื่องประดับ ชื่อ ทรงผม สีผิว และรูปลักษณ์ที่เหมือนเจ้าของยังไม่ได้กำหนด ไม่อนุมานจากข้อมูลที่ไม่มี

ภาพเน้นหน้าแบบที่ผู้ใช้ขอ หากต้องการให้ชุดอ่านออก เสนอ crop หัวถึงไหล่เล็กน้อย โดยเห็นคอเสื้อหรือฮู้ด และใช้หูฟัง แว่น หมวกเป็นตัวแยกสภาพ ภาพยังต้องอ่านออกเมื่อ Discord ย่อเล็ก

อารมณ์ตัวอย่างเพื่อคุยต่อ: ปกติ/ชิล, ตั้งใจ, ตื่นเต้น, เบื่อ/เซ็ง, ง่วง แต่ละแบบมีท่าขยับเล็ก เช่น กระพริบตา ยิ้ม เอียงหัว หรือหาว ตัวเลือกทั้งหมดนี้ยังเป็นข้อเสนอ ไม่ใช่ชุดสุดท้าย

## เชื่อมกับ App Mapping

เจ้าของตั้งภาพ/อารมณ์/ชุดเริ่มต้นให้แต่ละแอปได้ และเลือกอารมณ์ปัจจุบันเองได้ การปรับ mood ชั่วคราวควรเปลี่ยนหน้าตาโดยไม่ล้างการจับคู่แอป ข้อความ และลิงก์เดิม ระยะเวลาค้าง mood และกติกาการเลือกชุดจะคุยในรอบออกแบบ customization

ระบบตรวจว่าใช้แอปใดเพื่อนำกฎที่เจ้าของตั้งไว้มาใช้ ไม่อ้างว่าอ่านหรืออนุมานอารมณ์จริงของเจ้าของจากการเปิดแอป
